# Independent evaluation self-assessment

Mark each criterion Ready or Revise and point to the supporting evidence. This is a learning rubric, not a certification or recruitment score.

| Criterion | Ready means | Status | Evidence |
|---|---|---|---|
| Scope | The scientific question and review limits are explicit. | | |
| Evidence | Findings cite specific supplied material or recorded checks. | | |
| Calculations | At least two quantitative checks are correct and repeatable. | | |
| Scientific judgment | Replication, measurement scale, and claim limitations are addressed. | | |
| Balanced review | Correct statements are retained; mixed claims are separated. | | |
| Prioritization | Consequences justify the recommended order of action. | | |
| Communication | A concise corrected conclusion and specific next actions are provided. | | |
| Transparency | Synthetic data, assistance, and unperformed checks are disclosed. | | |

Do not average these into a pass score. Resolve any issue that could change the central conclusion. Keep the initial report and record revisions after viewing the worked review.
