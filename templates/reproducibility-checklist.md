# Reproducibility checklist

- [ ] Input provenance and data dictionary recorded.
- [ ] Sample identifiers and experimental units checked.
- [ ] Original supplied evidence preserved.
- [ ] Software versions and commands recorded.
- [ ] Random seeds recorded where relevant.
- [ ] Output paths and differences documented.
- [ ] Conclusions tied to verified evidence.
- [ ] Unperformed checks and uncertainties disclosed.
- [ ] Sources and AI assistance acknowledged.
