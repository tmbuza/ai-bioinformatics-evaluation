Run these commands from the repository root. The supplied scripts use base R; no additional R packages are required for these exercises.

Understand the outputs

A script completing successfully means its instructions ran. Some exercises deliberately report failed checks, such as mismatched identifiers or a rank-deficient design. Read the findings before deciding whether an analysis is usable.

The scripts overwrite their named outputs on rerun. Preserve previous results before changing inputs. Keep original teaching files separate from experimental copies, and document any modification.

Reference tables for ABE-004 through ABE-008 were calculated independently with Python. The R scripts were not executed in the authoring environment. Record your own observed results and software details; expected tables are comparison aids, not proof of an R execution.

Evaluation labels

Label Use when…
Supported Inspected evidence supports the claim within its stated scope.
Incorrect A check demonstrates an error or contradiction.
Not established Evidence is insufficient to decide.
Not applicable A criterion falls outside the task; give a reason.

For issues requiring action, assign Blocking, Major, or Minor according to scientific consequence. Use none when no correction is needed. Split statements that combine correct calculations with unsupported conclusions.

Troubleshooting

Problem First check or action
Rscript is not found Check whether R is installed and accessible from the terminal. Alternatively, use source("scripts/R/<script-name>.R") in an R session opened at the repository root, replacing the placeholder with the actual filename.
An input file cannot be opened Check your working directory and the extracted folder structure. In R, getwd() shows the current directory.
An assertion fails Inspect the message and corresponding input. Do not remove the check merely to let the script continue.
Results differ from a reference Compare input versions, identifiers, denominators, and numeric precision. Save the discrepancy before editing anything.
A chapter link cannot be resolved Confirm that both the link and _quarto.yml use the current filename. Microbiome is 04-microbiome-case.qmd; RNA-seq is 05-rnaseq-case.qmd.
Rendering produces no analysis outputs Run the verification scripts separately. Display-only code fences and eval: false keep analysis execution separate from book rendering.

A genuine error may be in the input, environment, or supplied script. Document it before proposing a correction.

Sharing checklist

Before sharing an evaluation, confirm that another reader can locate its evidence and distinguish:

  • Synthetic teaching materials from research data.
  • Supplied outputs from independently reproduced results.
  • Confirmed errors from missing evidence.
  • Your own work from assistance received.

Include input versions or fingerprints, software details where relevant, and unresolved limitations. Consult References for sources supporting the case-study concepts.

Scientific foundations

  • Microbiome interpretation: Relative abundance describes composition and does not directly establish absolute microbial quantities (Gloor et al. 2017).

  • RNA-seq study design: Complete confounding prevents separate estimation of batch and condition effects (Analyzing RNA-seq Data with DESeq2 n.d.).

  • Single-cell replication: Comparisons across conditions must account for biological replication rather than treating cells from the same donor as independent biological replicates (Squair et al. 2021).

  • Proteomics missingness: Interpretation depends on the missing-data mechanism and assumptions used for imputation (Lazar et al. 2016).

  • GWAS population structure: Genetic structure can confound association estimates and requires appropriate assessment and adjustment (Price et al. 2006).
