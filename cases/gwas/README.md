# GWAS: case materials

Original CDI synthetic counts for one fictional variant. Each participant occurs exactly once; all are stipulated unrelated. A and B are fictional genetic-background strata, not inferred ancestry estimates or real population labels. Carrier status is a binary teaching variable. There is no genotype matrix, allele dosage, phenotype covariate table, LD information, or real variant identifier.

The exercise illustrates confounding with descriptive carrier odds ratios. It is not a GWAS pipeline or a significance test. Read the response, save an initial review, run the base-R script from the repository root, then compare the worked review and Python-calculated reference tables.
