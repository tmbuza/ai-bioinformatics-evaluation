# RNA-seq: authoring specification

Status: planned; no dataset or verified analysis supplied yet.

Support level: Guided

Scenario: A synthetic two-condition expression study with sample metadata and a batch variable.

Question: Can the supplied design support the reported expression differences and interpretation?

## Required assets
- Small synthetic dataset with documented generation procedure and seed.
- Data dictionary identifying units, identifiers, experimental units, and missing values.
- Original AI-assisted response with provenance: model/date/prompt if actually generated, or clearly label as author-written simulated output.
- Supplied analysis script and outputs, including intentional issues where appropriate.
- Separate reference workflow, verified expected outputs, and explanations.
- At least one supported claim, one error, and one claim requiring more evidence.
- Case-specific reading from authoritative sources, verified before publication.

## Release checks
Confirm that errors are pedagogically intentional; the reference workflow is scientifically defensible; identifiers align; results reproduce; and no answer depends on private data or a paid AI service.
