# Proteomics: case materials

Original CDI synthetic teaching data; no real participants or proteins. Each sample represents one independent biological unit. Control samples C1–C3 and treated samples T1–T3 are unpaired. All intensities are already on a log2 scale; their normalization and identification provenance is intentionally absent. NA denotes an unquantified measurement, not zero abundance.

Read the simulated response, save an initial review, run the verification script from the repository root, then consult the worked review. Reference tables are Python-calculated expectations, not executed R outputs. Do not use this tiny matrix to select a production normalization or imputation method.
