# Evaluating AI-Assisted Bioinformatics Analyses

Scientific reasoning, reproducibility, and evidence-based feedback.

An independent, globally oriented CDI Quarto scaffold for original RNA-seq, microbiome, and single-cell evaluation cases.

## Status
Scaffold only. Includes chapter outlines, case specifications, a usable evaluation rubric, and report templates. It does not yet include datasets, executable case analysis, reference results, or completed worked solutions.

## Preview
Install Quarto, open this folder in VS Code or a terminal, then run:

```bash
quarto preview
```

To render HTML:

```bash
quarto render
```

Output is configured for docs/. Rendering does not execute R code. R and case-specific packages will be needed for future verification scripts, not for rendering this scaffold.

## Structure
Chapters 00–03 establish the framework; 04–06 specify original case studies; 07–08 support independent reporting. Appendices hold the rubric and reference-development notes. templates/ contains learner tools; cases/ contains authoring specifications; scripts/R/ reserves analysis workflows.

## Development sequence
1. Review and complete the foundations.
2. Implement and scientifically verify the guided RNA-seq case.
3. Apply the framework to microbiome and single-cell cases.
4. Add authoritative references, tested setup instructions, and worked explanations.
5. Pilot the exercises and revise unclear tasks.
6. Render, review accessibility and links, and package the finished practical.

Use original educational materials. Keep institutional branding, employer assessments, and recruitment requirements outside the core resource. Decide distribution and licensing terms before public release; no open-source license is implied by this scaffold.
